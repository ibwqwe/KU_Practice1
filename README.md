## О программе

OSEmulator — эмулятор для языка оболочки ОС.

**Этап 1. REPL**

**Цель:** создать минимальный прототип. Большинство функций в нём пока представляют собой заглушки, но диалог с пользователем уже поддерживается.

**Требования:**

1. Приложение должно быть реализовано в форме графического интерфейса (GUI).
2. Заголовок окна должен содержать имя VFS.
3. Реализовать простой парсер, который разделяет ввод на команду и аргументы по пробелам.
4. Реализовать команды-заглушки, которые выводят своё имя и аргументы: `ls`, `cd`.
5. Реализовать команду `exit`.
6. Продемонстрировать работу прототипа в интерактивном режиме. Необходимо показать примеры работы всей реализованной функциональности, включая обработку ошибок.
7. Результат выполнения этапа сохранить в репозиторий стандартно оформленным коммитом.

## Интерфейс

Приложение работает в форме графического интерфейса:

- **Заголовок окна** — `Эмулятор - VFS` (содержит имя VFS).
- **Область вывода** — отображает ввод пользователя и результат выполнения команд.
- **Поле ввода** — сюда вводится команда. Enter — выполнить.

Приглашение к вводу имеет вид `VFS$`, где `VFS` — имя виртуальной файловой системы.

## Поддерживаемые функции

### ls

**Описание**

На данном этапе команда реализована в виде заглушки. Выводит имя команды и переданные аргументы.

**Примеры использования**

Без аргументов.

Ввод:

```
VFS$ ls
```

Вывод:

```
ls: args=[]
```

С аргументами.

Ввод:

```
VFS$ ls -la /home
```

Вывод:

```
ls: args=['-la', '/home']
```

---

### cd

**Описание**

На данном этапе команда реализована в виде заглушки. Выводит имя команды и переданные аргументы.

**Примеры использования**

Без аргументов.

Ввод:

```
VFS$ cd
```

Вывод:

```
cd: args=[]
```

С аргументами.

Ввод:

```
VFS$ cd /tmp
```

Вывод:

```
cd: args=['/tmp']
```

---

### exit

**Описание**

Завершает работу приложения и закрывает окно.

**Примеры использования**

Ввод:

```
VFS$ exit
```

Вывод:

```
exit: завершение работы.
```

После этого приложение закрывается.

## Обработка ошибок

### Неизвестная команда

При вводе неподдерживаемой команды в область вывода выводится сообщение об ошибке.

Ввод:

```
VFS$ test
```

Вывод:

```
Ошибка: неизвестная команда 'test'
```

### Пустая строка

Если пользователь нажал Enter на пустой строке, ничего не происходит: ни ввод, ни вывод не отображаются.
