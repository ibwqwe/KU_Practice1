# OSEmulator

Эмулятор командной оболочки ОС. Балкизов И.М., группа ИКБО-20-25.

## О программе

Учебный проект — эмулятор командной строки, похожий на UNIX-подобные оболочки.

Текущий этап — **Этап 2. Конфигурация**.

Что уже умеет:

- окно на Tkinter, в заголовке имя VFS;
- разбор ввода на команду и аргументы;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- сообщение об ошибке, если команда неизвестна;
- приём аргументов `vfs=` и `script=` при запуске;
- выполнение стартового скрипта с комментариями.

## Запуск

Запускать нужно из корня проекта.

Обычный запуск:

```
run.bat
```

Или напрямую:

```
python src\main.py
```

## Аргументы командной строки

Формат: `имя=значение`. Можно указывать в любом порядке.

- `vfs=<путь>` — путь к VFS. Пока просто сохраняется, используется на следующем этапе.
- `script=<путь>` — стартовый скрипт, который эмулятор выполнит при запуске.

Примеры:

```
python src\main.py vfs=C:\data
python src\main.py script=scripts\demo.txt
python src\main.py vfs=C:\data script=scripts\demo.txt
```

## Стартовый скрипт

Текстовый файл с командами эмулятора. Что важно:

- строки, начинающиеся с `#`, — это комментарии, они пропускаются;
- пустые строки пропускаются;
- если команда неизвестна — эмулятор выведет ошибку и продолжит работу;
- в окне видно и ввод, и вывод, как будто пользователь вводит команды руками.

Пример (`scripts/demo.txt`):

```
# демонстрационный скрипт

ls
ls -la /home
cd /tmp

abracadabra
```

## Скрипты для запуска

В папке `scripts\os_scripts\` лежат `.bat`-файлы для проверки аргументов:

- `run_default.bat` — без аргументов;
- `run_with_vfs.bat` — только `vfs`;
- `run_with_script.bat` — только `script`;
- `run_all.bat` — оба аргумента.

## Функции в src\main.py

- `parse_args(argv)` — разбирает `vfs=` и `script=`.
- `run_command(text)` — выполняет одну команду, возвращает ответ и флаг выхода.
- `run_script(window, path)` — открывает файл скрипта и выполняет его построчно.
- `Window` — класс окна: область вывода, поле ввода, приветствие.
- `main()` — точка входа.

Настройка в коде: `VFS_NAME = "myVFS"` — имя VFS в заголовке окна и приглашении.

## Пример работы

Без аргументов:

```
myVFS$ ls
ls: args=[]

myVFS$ cd /tmp
cd: args=['/tmp']

myVFS$ qwerty
Ошибка: неизвестная команда 'qwerty'

myVFS$ exit
exit: завершение работы.
```

С аргументом `script=scripts\demo.txt`:

```
myVFS: введите команду (ls, cd, exit)
--- выполнение скрипта: scripts\demo.txt ---
myVFS$ ls
ls: args=[]
myVFS$ ls -la /home
ls: args=['-la', '/home']
myVFS$ cd /tmp
cd: args=['/tmp']
myVFS$ abracadabra
Ошибка: неизвестная команда 'abracadabra'
--- скрипт завершён ---
```
